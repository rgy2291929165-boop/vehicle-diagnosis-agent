# 当前可用的简历条目

## 推荐项目名称

新能源汽车故障诊断 Agent（RAG 与工具调用）｜2026.09–至今

## 正文

项目描述：面向新能源汽车充电异常与故障资料查询，构建结合知识检索、状态化工作流和大模型工具调用的维护辅助系统，支持信息补问、来源引用、异常转人工及本地工单审批。

技术栈：Python、FastAPI、LangGraph、Qwen、Pydantic、MCP、SQLite、Chroma、BM25/RRF、Docker Compose、pytest。

项目职责：

1. 构建文档切片、向量/BM25 检索与 RRF 融合评测，整理 12 篇资料和 60 条标注题目，区分开发集与冻结测试集，分析证据完整性及引用质量。
2. 使用 LangGraph 组织补问、只读工具查询、检索和转人工流程，加入参数校验、工具允许列表、调用预算与重复调用保护；基于 SQLite checkpoint 实现跨进程恢复和人工审批、编辑、拒绝及幂等工单提交。
3. 封装 stdio MCP 查询服务和 FastAPI 只读诊断接口，完成 Docker Compose 部署与离线自动检查；新增 Qwen 原生工具选择、工具结果回传和 JSON 引用解释路径，限制单任务最多 2 次模型请求、1 次只读执行。

项目成果：构建 60 条标注检索题目，完成 BM25、向量召回与 RRF 的可复现对照；最新发布快照通过 504 项离线测试及 20 条基础工作流案例，真实验证“原生工具选择→受控查询→带引用解释”链路。
