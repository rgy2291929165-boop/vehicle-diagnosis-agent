# 资料、数据类型与公开范围

## 包含的资料

`data/documents/w2-*.json` 为 12 篇公开资料的自建中文意译摘要；来源链接、片段与版本记录见 `evaluation/week2/SOURCE_NOTES.md` 和 `corpus_manifest.csv`。不将这些摘要称为厂家完整手册或授权维修库。

第五周 `source_inventory.json` 对充电口红灯及 CP_a054 两个主题记录人工核对的有限主张、出处与未知适用字段；`sources/` 是明确标记的有限摘录，不是完整网页快照。原始资料权利属于对应权利人，使用时请遵守原始来源规则。

## 数据类型

- 实际模型服务：Qwen 在线调用在历史烟测中真实发生，当前离线测试采用模拟响应。
- 本地资料：人工审核摘要，精确车辆年款/软件适用性仍未知。
- 业务输入：开发题和流程题为自建/合成问题，不是企业客户记录。
- DTC、车辆历史、库存及演示 VIN：显式模拟数据，不是车辆遥测或企业系统。
- 工单：本地教学业务数据，通过批准和幂等模块生成，不代表外部企业工单。

## 排除内容

公开包不含 `.env`、API Key、真实凭据、运行 SQLite/Chroma 数据库、模型权重、缓存、私人学习日志和原始模型烟测日志。测试内伪凭据与演示车辆 ID 为本地验证样例，不可用于真实认证。

项目尚未选择开源许可证。代码许可与第三方资料权利分开处理，公开可见不表示第三方资料权利转移。
